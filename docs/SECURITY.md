# Security boundaries

- Credentials are macOS Keychain values or explicitly selected CI environment references. No token literal belongs in configuration, request files, argv or logs. Keychain access and signed executable requirements need actual macOS validation.
- Validation and operation/Worker reference allowlists precede normal credential retrieval. This is declarative policy, not cryptographic sealing; repoctl's seal protocol is not yet integrated.
- Hardware providers fail closed. No PIV slots, PIN policies or touch policies are changed. age uses native software X25519 identities in this increment; wrapping a bearer token would not make it nonexportable.
- Cloudflare management and S3 object credentials are separate. Archive profiles are rejected when targeting the controller-receipts purpose. Worker bucket/secret allowlists must contain only receipt resources/application secrets. A Worker R2 binding grants bucket access; it is not append-only by itself.
- Worker tooling runs prebuilt modules in an isolated configuration directory. Human output and raw errors are discarded; structured IDs and remote readback form the contract. Token values briefly exist in process memory and the adapter/child environment. Allowed application secret values exist in an inherited pipe and process memory.
- age generates random keys per unique chunk. Plaintext hashes are lookup keys inside an encrypted vault index, not key material/public object keys. Cross-vault deduplication and convergent encryption are forbidden. Existing plaintext is staged briefly in private local files; cryptographic secure erasure on SSDs is not promised.
- Snapshots need trusted manifest ciphertext digests from outside the untrusted replica. age authentication does not prove who published a replacement manifest. Local descriptors/index-head records are not protected against a fully compromised account/device.
- Full replicas must be independently restorable with recovery material retained elsewhere. Schemas reserve R2/B2/Drive destinations and evidence, but B2/Drive transfer adapters remain unimplemented. Copying ciphertext requires no decryption identity. Primary eviction is prohibited.
- R2 retention is administrator-removable. Multipart currently requires verified Indefinite locks; administrators can still remove those safeguards. No compliance-mode WORM, HIPAA claim or administrator-independent archive guarantee is made.
- Restore checks traversal, symlinks and normalized case collisions, verifies ciphertext and plaintext, and publishes only a fresh destination after assembly. Generic snapshots reject raw `.git` administration paths. Git capture keeps hooks/configuration in quarantine and never activates them automatically.
- Source repositories are not rewritten. Capture of active directories is not atomic; metadata race checks do not constitute an APFS snapshot. Missing external LFS/submodule content is not silently called complete.
- Remote mutating HTTP operations are not automatically retried after uncertain results. Multipart part retries are bounded; acknowledged parts are reconciled before resume. Journals contain destination/fingerprint/part metadata, never credentials. Completion uncertainty remains a manual reconciliation case.
- No broker, hosted service, DNS administration, production endpoint or repoctl promotion engine is implemented.
